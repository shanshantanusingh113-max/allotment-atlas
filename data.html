03 · Event calendar

The dates that move demand

Each row is an event type; each bar is one occurrence. Darker bars lift demand more. Festivals that move between years, like Diwali, Holi and Ramadan, are why the forecaster beats a simple last-year copy.

05 · Bring your own data

Swap in a real dataset

The engine reads a JSON catalog and, optionally, a daily history CSV. Replace either and every page updates.

History CSV · required columns
datestay date, YYYY-MM-DD
destdestination code in the catalog
bookingsunits sold for that stay date
lostsearches that ended on sold-out (0 if unknown)

Optional: searches, cancellations, adr, event_intensity. At least 400 days are needed to learn a yearly pattern.

Run it
cd backend ATLAS_CATALOG=my_catalog.json \ python -m scripts.run_custom \ --history my_history.csv \ --out ../frontend/data/atlas.json

The catalog is checked before anything runs: unknown destinations, prices below cost and overlapping ids are reported with a clear message.
